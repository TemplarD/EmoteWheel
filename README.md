# Emote Wheel for WoW 3.3.5a

Колесо эмоций для World of Warcraft 3.3.5a с красивым интерфейсом в стиле Sims.

Emote wheel for World of Warcraft 3.3.5a with beautiful Sims-style interface.

## Особенности версии 2.0.0 / Version 2.0.0 Features

- 🎯 Колесо эмоций вокруг курсора / Emote wheel around cursor
- 🎨 Цветные группы эмоций / Colored emote groups  
- ⚙️ Настройки в интерфейсе WoW / Settings in WoW interface
- 📝 Лог выполненных эмоций / Executed emotes log
- ⌨️ Настраиваемая клавиша вызова / Customizable trigger key
- 🌍 Поддержка локализации (русский/английский) / Localization support (Russian/English)
- 🖼️ База данных иконок для групп / Icon database for groups

## Установка / Installation

1. Скачайте последнюю версию / Download latest version
2. Распакуйте в `World of Warcraft\Interface\AddOns\` / Extract to `World of Warcraft\Interface\AddOns\`
3. Переименуйте папку в `EmoteWheel` / Rename folder to `EmoteWheel`
4. Перезапустите игру / Restart the game

## Использование / Usage

- **По умолчанию / Default**: Shift + ПКМ / Shift + RMB
- **Команды / Commands**: 
  - `/ew show` - показать колесо / show wheel
  - `/ew config` - настройки / settings
